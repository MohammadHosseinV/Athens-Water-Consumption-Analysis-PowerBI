# تحلیل مصرف آب شهری آتن

یک پروژه تحلیل داده بر اساس داده‌های عمومی مصرف آب شهری منتشرشده توسط شرکت آب آتن (**EYDAP**).
هدف پروژه، طراحی یک فرایند داده قابل‌تکرار در SQL Server برای یکپارچه‌سازی، اعتبارسنجی، مدل‌سازی تحلیلی، تحلیل با SQL و گزارش‌سازی در Power BI است.

> **وضعیت پروژه:** در حال توسعه  
> **مرحله فعلی:** یکپارچه‌سازی و اعتبارسنجی داده‌ها

---

## ابزارها و فناوری‌ها

- SQL Server
- T-SQL
- ETL
- Power BI

> استفاده از Python عمداً خارج از محدوده این پروژه در نظر گرفته شده است.

---

## معرفی مجموعه‌داده

این پروژه دو دوره از داده‌های منبع را با پوشش زمانی **ژانویه ۲۰۲۱ تا مارس ۲۰۲۵** با یکدیگر ترکیب می‌کند.

| شاخص | مقدار |
|---|---:|
| تعداد کل ردیف‌های منابع | ۲۶۰٬۱۳۸ |
| تعداد ردیف‌های جدول یکپارچه | ۲۶۰٬۰۶۷ |
| تعداد گروه‌های تجمیع‌شده | ۷۱ |
| تعداد گروه‌های مصرف | ۵ |

مهم‌ترین ستون‌های داده عبارت‌اند از:

- کد پستی و نام منطقه
- گروه مصرف
- کل مصرف آب
- تعداد روزهای ثبت مصرف
- تعداد انشعابات
- میانگین مصرف روزانه
- سال و ماه مرجع

---

## معماری پروژه

```text
داده‌های منبع
      ↓
لایه خام و Staging
      ↓
ترجمه و یکپارچه‌سازی
      ↓
اعتبارسنجی و پاک‌سازی
      ↓
مدل تحلیلی
      ↓
تحلیل با SQL
      ↓
Power BI
```

---

## پیشرفت فعلی

اقدامات انجام‌شده تاکنون:

- ورود هر دو مجموعه‌داده منبع به SQL Server
- ایجاد ساختارهای RAW، ‏Staging و ترجمه
- انجام پروفایلینگ اولیه داده‌ها
- بررسی کلیدهای کاندید و دانه‌بندی داده
- ترکیب دو دوره زمانی داده‌ها
- شناسایی و تجمیع ۷۱ گروه چندردیفی
- بارگذاری ۲۶۰٬۰۶۷ رکورد در جدول یکپارچه
- تطبیق تعداد ردیف‌های منبع و مقصد
- بررسی اولیه مقادیر NULL و روابط جغرافیایی

تمرکز فعلی پروژه، تکمیل اعتبارسنجی داده‌های منبع و مقصد پیش از شروع پاک‌سازی و مدل‌سازی تحلیلی است.

---

## یافته‌های مهم

- هیچ ردیف کاملاً تکراری در داده‌های منبع شناسایی نشد
- کلیدهای کاندید بررسی‌شده در همه رکوردها یکتا نیستند
- بین کد پستی و نام منطقه رابطه یک‌به‌یک وجود ندارد
- برخی اطلاعات جغرافیایی دارای مقدار گمشده هستند
- ستون‌های `AreaGreek` و `AreaEnglish` الگوی NULL یکسانی دارند
- `AverageDailyConsumption` یک معیار غیرجمع‌پذیر در نظر گرفته شده است
- دانه‌بندی نهایی مدل تحلیلی همچنان در حال اعتبارسنجی است

به دلیل ارتباط یک کد پستی با چند منطقه، مقادیر گمشده نام منطقه صرفاً بر اساس کد پستی تکمیل نمی‌شوند.

---

## رویکرد اعتبارسنجی

داده‌های یکپارچه‌شده از طریق بررسی‌های زیر اعتبارسنجی می‌شوند:

- تطبیق تعداد ردیف‌های منبع و مقصد
- بررسی رکوردهای تکراری در دانه‌بندی انتخاب‌شده
- اعتبارسنجی معیارها و قواعد تجمیع
- بررسی محاسبه میانگین مصرف روزانه
- مقایسه توزیع مقادیر NULL
- اعتبارسنجی بازه زمانی و گروه‌های مصرف

---

## مدل تحلیلی پیشنهادی

ساختار پیشنهادی پروژه یک مدل ستاره‌ای با اجزای زیر است:

- `FactWaterConsumption`
- `DimDate`
- `DimGeography`
- `DimConsumptionClass`

مدل نهایی پس از اعتبارسنجی دانه‌بندی تحلیلی و روابط جغرافیایی طراحی خواهد شد.
